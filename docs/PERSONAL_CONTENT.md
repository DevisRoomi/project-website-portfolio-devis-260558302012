## 2. Karya Rekayasa Software Unggulan (Showcase Carousel)

### Proyek 01: DEVIS® Interactive 3D Portfolio (Showcase Utama)
- **Kategori:** Front-End Architecture & Creative Web
- **Fungsi / Masalah:** Menghadirkan identitas visual rekayasa berstandar editorial dengan pengalaman interaktif 3D orbital tanpa mengorbankan performa Lighthouse.
- **Fitur Utama:** 3D Radial Arc Carousel, Two-way Sync Rotary Dial Controller, Dynamic Depth Calculation (`rotateY`, `translateZ`), Kinetic Typography.
- **Tech Stack:** React, Vite, Tailwind CSS, GSAP, CSS 3D transforms.
- **Repositori:** `https://github.com/DevisRoomi/project-website-portfolio-devis-260558302012`

### Proyek 02: CapyQuest – Cozy Habit RPG & Daily Companion
- **Kategori:** Fullstack Modern JavaScript / Gamification
- **Fungsi / Masalah:** Membantu produktivitas harian dan pelacakan kebiasaan (*habit tracking*) dengan mekanisme gamifikasi RPG dan visual interaktif yang menyenangkan.
- **Fitur Utama:** Habit & Quest RPG System (EXP & Gold rewards, auto-streak flame counter 🔥), Maskot Capybara interaktif (*petting response* & toko aksesoris onsen), Capy Zen Pomodoro Focus Timer.
- **Tech Stack:** Bun runtime, Hono backend API, React 19, `bun:sqlite` database native.
- **Aset Visual:** Thumbnail resmi 1048x700px siap pakai.

### Proyek 03: BASOKU – Sistem Manajemen & Kalkulator Cerdas F&B
- **Kategori:** Database Architecture & Business Management System
- **Fungsi / Masalah:** Digitalisasi alur operasional peracikan, perhitungan bahan baku, dan pemesanan UMKM F&B secara presisi dan transparan.
- **Fitur Utama:** Smart Recipe Calculator (rasio daging, tepung, bumbu, tarif selepan), Saved Recipes, Checkout & snapshot harga terintegrasi, Konsultasi cerdas resep.
- **Tech Stack:** Laravel, Livewire, MySQL, ERD Relasional presisi.
- **Dokumentasi:** Data requirement, diagram relasi database (dbdiagram), flowchart admin & customer.

### Proyek 04: Setoran Companion – Sistem Pencatatan Tahfidz Pesantren
- **Kategori:** Cloud Web Application
- **Fungsi / Masalah:** Menggantikan pencatatan manual setoran hafalan Al-Qur'an di lingkungan pesantren menjadi sistem cloud digital yang rapi, transparan, dan terukur.
- **Fitur Utama:** Dasbor progres santri, input harian setoran tahfidz, laporan analitik bulanan santri, manajemen ustadz pengampu.
- **Tech Stack:** React, Tailwind CSS, Lovable Platform, Cloud Database.
- **Live Demo:** `https://setoran-companion.lovable.app/`
